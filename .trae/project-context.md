## Qual é o sistema

O sistema chamado Salestone

## Qual é o objetivo

Facilitar a análise de chamadas de vendas entre cliente e vendedor, focando na análise da técnica de venda do vendedor, isso utilizando IA.

## Como funciona a arquitetura geral

Como está na versão MVP do projeto, o usuário irá subir o audio da chamada de vendas, e o sistema irá analisar o audio, e retornar uma análise da técnica de venda do vendedor.

## Tecnologias usadas

- Java 21
- Spring Boot 4.0.0
- MySQL
- Maven
- Docker
- Lombok

## Requisitos funcionais chave

- Subir o audio da chamada de vendas
- Analisar o audio, e retornar uma análise da técnica de venda do vendedor
- Exportar análise em PDF
